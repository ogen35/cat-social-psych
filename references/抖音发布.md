# 抖音发布：双封面 ＋ 标题 ＋ 爆款简介

> **默认做法（问题链版）**：`output/抖音文案.txt` 只写标题三选一、作品简介、置顶评论，**不带话题、不带页码**（用户 2026-11-07 定）。下文第 4 节的话题只在用户要时加。

这个系列以抖音为主。每一集除了成片，还要交三样东西：**竖封面和横封面**、**三个备选标题**、**一段能直接复制的爆款简介**（带话题）和置顶评论。都写在 film.py 的 `META` 里，出片时自动生成到 `output/`。

## 1. 封面：爆款模板，不截静帧

抖音的封面在主页九宫格、搜索结果、双列推荐里被看到，要在一眼之间让人想点。**不要用片子里的静帧**，用爆款封面模板：

| 元素 | 规则 |
|---|---|
| 两行大字 | 上行 `line1` ≤ 8 字（交代情境）；下行 `line2` ≤ 7 字（冲突、反常识或数字），字号最大；`hi` 是下行里标黄的那个词 |
| 主角大头 | `who` 主角、`expr` 表情要夸张（shock / smug / flat / sad）、`emote` 头顶的大号「！」或「？」；身子出画，脸占下半部 |
| 背景 | `bg` 这一集的照片（自动像素化、压暗、虚化，`bg_kw` 调裁切位置和色调）或纯色 `(r, g, b)`；不要满屏细节 |
| 概念标签 | `tag` 概念名，青绿贴纸 |
| 系列角标 | 右上角「猫说心理学 · 期数」，期数从集目录名开头的数字自动取，也可写 `no` |
| 小道具 | 可选 `prop=函数(fr, 布局)`：一个点题的小东西（闹鬼的电视、碎花瓶），放在角落 |
| 避让 | 左上角留给「置顶」标签，左下角留给播放量，都不放字 |

一次出三张，都按自己的画幅重新排版：

| 文件 | 尺寸 | 用在哪 |
|---|---|---|
| `封面_竖屏_3x4.png` | 1080×1440 | 抖音电脑端的**竖封面**、主页九宫格；小红书 |
| `封面_横屏_4x3.png` | 1440×1080 | 抖音电脑端的**横封面**、搜索结果 |
| `封面_9x16.png` | 1080×1920 | 手机 App 发布时选的封面；视频号 |

写法：

```python
COVER = dict(line1='看完恐怖片', line2='一响就是贼？', hi='贼', who='大宝', expr='shock', emote='!',
             bg='素材/图/living_room_night_c02.jpg', bg_kw=dict(fx=0.85, tint=(36, 46, 96)), tag='启动效应', prop=cover_prop)
META = dict(cover=COVER, …)
```

标题怎么写：上行说「谁、在什么情况下」，下行是让人想点的那半句（问句、反常识、数字），和抖音标题、简介首句用同一个钩子。九宫格示意见 `/root/mao/素材/封面模板_主页九宫格示意.jpg`。

旧写法（`cover` 是函数、另写 `cover_h`）还能用，`--check` 会提醒改成模板。

## 2. 标题（三个备选，每个 ≤ 30 字）

抖音的「作品标题」会参与搜索。三个标题各用一种钩子，**每个都带搜索词**（概念名或观众会搜的场景词）：

| 写法 | 例子 |
|---|---|
| 反问 ＋ 概念名 | 朋友已读不回，你第一反应是什么？基本归因错误 |
| 误解 ＋ 概念名 | 已读不回就是讨厌你？基本归因错误了解一下 |
| 反常识 ＋ 概念名 | 聪明人反而更容易冤枉别人？基本归因错误 |

标题里的说法要和书一致：书说「更容易」，就别写成「越……越……」。

## 3. 爆款简介：五行公式

简介在手机上**折叠后只露第一行**，所以第一行就是钩子；后面几行给「看完能带走的东西」，让人愿意收藏、评论。整段（不含出处和话题）≤ 150 字。

| 行 | 写什么 | 要求 | 例子 |
|---|---|---|---|
| ① 首句钩子 `hook` | 戳中痛点或推翻一个想当然 | ≤ 20 字；不用「震惊」「必看」 | 已读不回≠讨厌你，别再脑补一整晚了 |
| ② 干货 `points`（2–3 行） | 概念名 ＋ 大白话翻译；书里最反常识的一个发现；一个能马上用的办法 | 每行一件事；搜索词至少出现一次 | 心理学管这叫基本归因错误：把处境的锅，算在人头上。 |
| ③ 互动问题 `ask` | 一个好回答的问题：对号入座、讲经历、二选一 | 以问号结尾 | 你被谁冤枉过？还是冤枉过谁？ |
| ④ 收藏或下期 `next` | 给一个收藏的理由，或预告下一集 | 自然，不喊口号 | 收藏这期，下次脑补之前先看一眼👀 |
| ⑤ 出处行 `source` | 拟人演绎 ＋ 书名章节 | 括号里一行 | （猫咪为拟人演绎，知识来自迈尔斯《社会心理学》第3章） |

写法要点：
- 用「你」，像跟一个人说话；一行一句，不写大段。
- 表情最多 1–2 个，放句尾，不放开头。
- 干货要能单独成立：没看视频的人读完简介，也学到一点东西（这是收藏的理由）。
- 数字和结论以书为准，带不了页码的不写。
- 不写：绝对化用词（一定、所有人、100%、科学证明）、限流词（震惊、必看、全网）、引流词（私信、加微信、领取、点击链接）。

## 4. 话题和置顶评论

**话题 3–5 个**，按这个顺序配：

1. 概念词：`#基本归因错误`
2. 场景词（观众会搜的）：`#已读不回`
3. 领域词：`#心理学`
4. 系列词：`#猫说社会心理学`
5. 可选的泛流量词：`#涨知识`

**置顶评论**：补一个书里的例子，或抛第二个问题，带动评论区。例如「书里的例子：有人在高速上飞驰而过，我们觉得他好斗，却没想到他也许正赶着开会、快迟到了。你最近冤枉过谁？」

发布时在「作品声明」里勾选「内容由AI生成」（配音是 AI 合成的）。

## 5. 写进 film.py

```python
META = dict(
    title='第3章 · 基本归因错误',
    cover=COVER,          # 爆款封面模板（见第 1 节）：自动出 9:16、3:4、4:3
    sources=[...],
    publish=dict(...),    # 视频号等平台的通用标题和简介
    douyin=dict(
        keyword='基本归因错误',
        titles=['…', '…', '…'],
        hook='…',
        points=['…', '…', '…'],
        ask='…？',
        next='…',
        source='（猫咪为拟人演绎，知识来自迈尔斯《社会心理学》第3章）',
        tags=['基本归因错误', '已读不回', '心理学', '猫说社会心理学', '涨知识'],
        pinned='…'),
    platforms={'小红书': dict(titles=[...], desc=...)},
)
```

出片后 `output/发布文案.md` 里有「作品标题」「爆款简介（整段复制）」「置顶评论」三块，简介放在代码块里，整段复制即可。
