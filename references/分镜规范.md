# 分镜.json 规范 ＋ Vox 竖屏规则

一集＝一个 `分镜.json`，build_episode.py 读它出片。完整可运行的例子：`assets/示例_第6章从众/分镜.json`。

## 1. 字段

```jsonc
{
  "episode": "第6章-从众-大比的周一选题会",  // 集名（发布文案标题用）
  "title": "明知是错的，你也会【跟着选】？",   // 顶部标题栏（默认值），【】高亮；≤16 字最好
  "theme": "vox",                           // 色板：vox（默认，Vox 实测：旧纸、近黑、一种红）；也可 paper wood snow bauhaus 等；整集一套
  "voice": "zh-CN-XiaoyiNeural",            // 可省；旁白音色。不写就用 角色库/角色.json 里 _旁白 的 voice；角色台词用角色自己的 voice
  "rate": "+20%",                           // 可省；语速，默认 +20%（约 5.5 字/秒）。用户嫌慢就 +25%，嫌快就 +12%
  "sources": [                              // 必填：书的章节＋每个研究的出处
    "戴维·迈尔斯《社会心理学》（第11版），第6章 从众和服从",
    "Asch, S. E. (1956). Psychological Monographs, 70(9)"
  ],
  "cover": {                                // 可省但强烈建议；Vox 调查桌风格的 3:4 封面，字段见第 5 节
                                            // focus 的 y 写成这张照片里猫眼睛的高度（0..1）：封面只露出照片约一半的高度，写错就只剩额头或下巴。生成后一定看一眼 封面.png
    "image": "../角色库/大比/01_脸部特写_委屈.jpg", "title": "明知是错的\n你也会【跟着选】？",
    "sub": "阿施从众实验", "big": "37%", "focus": [0.5, 0.3], "circle": [0.29, 0.1, 0.34, 0.52]
  },
  "publish": {                              // 可省但强烈建议；写进 发布文案.md
    "titles": ["…", "…", "…"], "desc": "…", "tags": ["社会心理学", "…"], "pinned": "…"
  },
  "disclaimer": "…",                        // 可省；简介里的拟人声明，默认「本系列猫咪均为拟人演绎，故事纯属虚构；心理学实验和数据来自真实的人类研究」
  "shots": [ { … }, … ]
}
```

每一镜（shot）：

```jsonc
{
  "say": "大比明明觉得B更好，开会时却【举手选了A】。",   // 口播一句（配音＋字幕），【】在字幕里高亮。一镜 1–2 句，配音 ≤8 秒
  "who": "大比",                             // 可省；写了＝这句是角色台词：用角色的声音念，字幕前面加「大比：」。台词 ≤12 字，单独一镜
  "mood": "悬疑",                            // 情绪：悬疑 紧张 揭晓 反转 轻松 平叙 温暖。决定配乐、配音语气语速、画面压暗和推近；没写就沿用上一镜。见 声音与张力.md
  "tone": "得意洋洋，拖长音",                 // 可省；豆包配音时这一句的语气（覆盖 mood 给的语气）。角色台词最常用：委屈地小声说、不耐烦地打断、憋着笑
  "title": "…",                              // 可省；段落标题：从这一镜起换顶部标题，一直保持到下一个 title（换的那一镜会弹入）
  "title_once": "…",                         // 可省；只这一镜换标题（揭晓数字、反转），下一镜回到段落标题
  "pause": 0.15,                             // 可省；口播念完后多停几秒。默认 0.15，节奏要紧；只有提问后（让观众猜）给 0.5–0.6
  "camera": "snap",                          // 可省；这一镜用快推、快移（只给揭晓、反转、关键数字）
  "cues": [ … ]                              // 画面事件，见下
}
```

镜头时长不用写：有配音时＝配音长度＋pause；无配音时按 4.5 字/秒估（含标点）。**单镜不能超过 8 秒**，超过了把 say 拆到两镜。全片 60–120 秒、15–30 镜（超过 125 秒红灯）；90 秒以上的长片，每一段的第一镜写一个 `title`，让顶部标题栏随段落换。

## 2. cue 怎么写

| kind | 字段 | 画面 |
|---|---|---|
| `image` | `image`（路径相对分镜.json；角色库在项目根目录，集目录里写 `../角色库/…`）、`text`（可选，左下角黑底撕边标签，≤14 字）、`fit:"cover"`＋`focus:[fx,fy]`（可选，按焦点裁满）、`halftone`（照片**默认 true**＝灰度 45° 网点，这是 Vox 的照片语言；证据卡保持原样；个别照片要原色才写 false） | 冲印件滑到桌上，镜头停住时占画面八九成。角色剧照、道具卡、知识卡都用它（卡片都是 make_card.py 生成的 png） |
| `highlight` | `mark: 0`（证据卡上第 0 个【】重点，坐标自动取）或 `rect: [x,y,w,h]`（照片上，0..1 相对整张图） | 荧光笔扫过 → 红笔圈住 → 镜头推近那一块（照片上只画红圈）。卡片上的【】重点（聊天里的关键一句、纪要的表决结果、气泡里的关键词）都能 mark |
| `point` | `text`（≤14 字） | 横线索引卡，逐字打出来 |
| `title` | `text`（≤14 字） | 黑底白字标签条，打字。适合收尾点题，不当开场 |
| `accent` | `on`/`at`、`sfx`（默认 hit）、`slam`（大字，【】黄色）、`sub`、`blackout`、`pulse`、`drop` | 重音：音效＋白闪＋震屏（＋大字砸入）。揭晓情绪下先抽空配乐再砸。一集 2–4 个，见 `声音与张力.md` |
| `sfx` | `name`、`on`/`at`、`gain`、`dur`（riser 用） | 单独一个音效：whoosh hit boom riser ding pop tick heartbeat glitch scratch sting |

**时间**：每个 cue 用 `on` 或 `at` 定时，二选一：

- `"on": "37%"`：口播念到「37%」这个词时出现（有配音时按逐词时间戳对齐，最准）。`on` 的词必须出现在这一镜的 say 里（去掉【】后）。
- `"at": 1.2`：本镜第 1.2 秒。
- 都不写：第一个 cue 在 0 秒，其余均分。

一镜 **1–3 个 cue** 最舒服，不超过 4 个。

**猫图上的 rect 怎么定**：先用 Read 看图，估一个框（猫脸、爪子、眼睛），然后 `build_episode.py` 出片后看 `output/抽帧.jpg`，或者单渲一镜的静帧核对（见 SKILL.md「单镜调试」）。目测的框常偏 20–30%，宁大勿小。

## 3. Vox 竖屏规则（从 huashu-art-motion y2_vox 提炼）

Vox 的核心：**论证摆在一张有真实材料的桌面上**——照片、剪报、档案卡，相机像调查记者的眼睛在桌上移动，线和笔一顿一顿地画上去。证据感来自「这些东西是真的被放在这里的」。

1. **真实材料当主画面。** 猫的真实照片、证据卡（make_card.py）占画面八九成。整集里**没有图的镜头不超过三成**，否则就是翻 PPT。
2. **第一帧就是事件。** 镜01 第一个 cue 是 `image`（at 0），不是 title。
3. **红圈只给每段的重点。** highlight 一段一个、一集 3–5 个，相邻两镜不要都圈；其余的重点交给重音（accent）和音效。数字揭晓用 accent 的大字，不用红圈。
4. **揭示方式要轮换。** 「滑入 → 标签 → 荧光笔红圈」连用不超过 3 次。可用的揭示：直接切到下一张图、highlight 推近、红线连到下一张、索引卡打字、标题条。**不要每一镜都 highlight**（每镜都往里推一次＝节奏单一）。
5. **推进去要拉出来。** highlight 推近之后，下一镜换一张图（硬切本身就是「拉出」）；不要连着三镜都在推近。
6. **快推只给重音。** `camera:"snap"` 一集最多 2–3 次：揭晓答案、反转、关键数字。
7. **上屏字少。** 标签、索引卡、标题条 ≤14 字；口播原文交给字幕。屏上的数字和口播必须是同一个数。
8. **相邻两镜换构图、不换画风。** 同一张图不要在相邻两镜开头重复；整集一个 theme。
9. **结尾落在猫身上。** 最后一镜用猫图（可以带标签或 note 卡），不落在纯字卡。
10. **颜色少。** 桌面纸色、墨色、一种红（accent），荧光黄只用来划重点。**猫照片一律灰度网点**（彩色照片在 Vox 桌面上会跳出来，像从别的片子里拿来的）。
11. **片子里不放章节标题。** 顶部只放钩子标题；书名和章节写在发布文案的出处里，读书笔记卡底部的小字出处保留。
12. **故事段靠道具卡推进，角色剧照给反应。** 一个情节＝一张道具卡（聊天、纪要、日记、动态、热搜），接一张角色剧照（谁看到了、什么表情）。连着两张道具卡之间最好插一张剧照，否则像在读文件。
13. **每个角色本集第一次出场时，剧照上贴一次名牌标签**（scene 卡的 `tag`：「大比 · 喵喵公司」），之后不用再贴。

## 4. 画面版式（1080×1920）

```
┌─────────────────────┐ 0
│  （抖音状态栏/搜索）   │
│  明知是错的你也会跟着选？│ ← title，【】黄色
├─────────────────────┤ 360
│                     │
│   Vox 桌面（素材、     │ ← 内容区 1080×1000
│   红线、荧光笔、相机）   │
│                     │
├─────────────────────┤ 1360
│   字幕一行，【】黄色    │ ← 约 y=1400–1480
│                     │
│  （抖音底部：账号名、   │ ← 平台 UI 会盖住这里，不放内容
│   文案、音乐条）        │
└─────────────────────┘ 1920
```

上下两条深色带（主题的墨色）是有意的：抖音的 UI 压在上下两端，内容和字都落在安全区里；右侧点赞栏约 150px 宽，内容区里的图是居中的，红圈和关键字别放在最右边 10%。

## 5. 封面（cover）

Vox 调查桌 × 抖音爆款版式，1080×1440（3:4，抖音主页网格和推荐流都按这个比例裁）：

```
┌──────────────────┐
│ 明知是错的          │ ← title：两行大字，每行 ≤7 字，\n 换行
│ 你也会[跟着选]？     │   【】里的词＝荧光笔色块（一个就够）
│ ┌──────────────┐ │
│ │ 灰度网点猫照片   │ │ ← image＋focus：猫脸要大，占照片一半以上
│ │   (红圈)  ┌───┐│ │   circle：手画红圈圈住猫脸或关键动作
│ │          │37%││ │ ← big：可选，唯一的红色大数字（钉在照片上的纸片）
│ └──────────────┘ │
│ ■阿施从众实验■      │ ← sub：黑底撕边标签，≤10 字，说清这集讲什么
│ （留白：网格里点赞数） │
└──────────────────┘
```

爆款封面的几条规律：标题是钩子不是题目（问句、反常识、数字）；一个视觉锚点（猫脸或数字），不堆元素；关键词用色块高亮；同一系列版式固定，主页看起来整齐（`series` 角标可选，如「猫说心理学 01」）；最下面 120px 不放字（主页网格左下角会压点赞数）。封面标题和第一镜的钩子呼应，但不必一字不差。位置要微调时用 `photo_top`、`big_top`、`sub_top`（px）。

## 6. 常见红灯怎么改

| 红灯 | 改法 |
|---|---|
| 某镜超过 8 秒 | 把 say 从句号或逗号处拆成两镜，第二镜换一张图或加一个 point |
| 上屏文字超过 14 字 | 留关键词，其余交给口播 |
| on 的词不在口播里 | on 要和 say 里的字一模一样（去掉【】之后） |
| highlight 写了 mark 但没有坐标文件 | 那张图不是 make_card.py 生成的；照片用 rect |
| sources 为空 | 写书的章节，以及每个提到的研究的作者、年份、期刊 |
