# 画风模板 v3：天真当代艺术插画（2026-11-07 用户给的四张参考图）

用户给了四张参考图，要的是它们共同的「抽象艺术风格」。**参考图是别人的作品：只用文字描述风格，不上传、不写作者名字、不写「像某某」。**

以后所有出图（角色、场景、道具、镜头关键帧）都用这个模板拼提示词：

```sh
python3 $S/scripts/style_prompt.py character|scene|prop|shot "主体描述（英文）" [--palette 橙绿|紫黄|粉薄荷|钴蓝粉] [--extra "..."]
```

  - **直接出图**（角色、场景、道具、关键帧）：**Style Image V8.2**（`mj-v8.2`）。

## 2. 四张图的共同点（就是我们的画风）

| 维度 | 写法 |
|---|---|
| 气质 | 天真、稚拙的当代艺术插画（naive contemporary art），一本正经的荒诞幽默（deadpan absurd humor） |
| 线条 | 手画的、微微抖动的黑色描边（wobbly hand-drawn black outlines） |
| 色彩 | 大块高饱和平涂，**一组强互补色**做主调，再加黑、白和一点红 |
| 质感 | 水粉笔触或彩铅排线的手绘肌理（gouache brushstrokes / colored-pencil hatching），不是电脑渐变 |
| 造型 | 几何化、简化、比例怪趣；眼睛是圆眼加小黑点瞳孔，表情面无表情或一脸无辜 |
| 空间 | 透视压扁、略微俯视；室内生活场景，满是图案和小物件 |
| 常见元素 | 盆栽（龟背竹、棕榈）、墙上的抽象画框、黑白格地板、圆地毯、吊灯、复古电视、瓷砖墙、条纹 |

**主调色板**（每个画面选一组）：

| 名字 | 主色 | 对比色 | 适合 |
|---|---|---|---|
| 橙绿 | 焦橙 burnt orange | 祖母绿 emerald green | 浴室、厨房、热闹 |
| 紫黄 | 紫蓝 violet blue | 芥末黄 mustard yellow | 夜晚、悬疑、揭晓 |
| 粉薄荷 | 玫粉 hot pink | 薄荷绿 mint green | 轻松、日常、吐槽 |
| 钴蓝粉 | 钴蓝 cobalt blue | 泡泡糖粉 bubblegum pink | 结论、金句、温暖 |
