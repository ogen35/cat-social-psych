# 角色设定：喵喵剧团

这个系列是**拟人化的猫咪情景剧**：三只固定的猫在公司、学校、小区、网上遇到人类会遇到的事，每集讲一个心理学概念。猫不变，概念每集都变；观众记住角色，才会追更、在评论区说「我就是大比」。

## 三个主角（v4 像素造型）

三只猫的原型是用户自己的猫；v4 把它们画成**单色、简约、各有一个记忆点**的像素小猫（`scripts/pixel/chibi.py`，设定图见 `assets/示例_v4_第3章基本归因错误/静帧/角色设定_v4.png`）。

| 角色 | 造型 | 性格 | 口头禅 | 声音（豆包设计音色） | 最适合主演 |
|---|---|---|---|---|---|
| **大比** | 奶白 · 深色耳尖和尾巴（布偶）· 蓝眼睛 · 八字眉 | 乖巧、心软、没主见，特别在乎别人怎么看；怕冲突，心里有想法也不敢说，爱脑补 | 「大家都这么说……」 | 二十出头的男生，偏亮、软；小心翼翼，句尾发虚 | 从众、焦点效应、透明度错觉、基本归因错误（脑补的那个）、自我妨碍、影响偏差 |
| **胜利** | 金黄 · 头顶小王冠 · 竖起的大尾巴 · 眯眼得意 | 自信过头、爱吹牛、行动派；经常翻车，翻车了也不认 | 「稳赢！」 | 二十多岁的东北姑娘，嗓门亮、语速快、说话带笑 | 自我服务偏差、规划谬误、过度自信、控制错觉、后见之明 |
| **大宝** | 灰蓝 · 耳尖簇毛（缅因）· 额头三道纹 · 死鱼眼，个子大一号 | 冷静、话少、嘴硬，爱唱反调；偶尔一句话说到点子上 | 「我不。」 | 三十岁左右的男人，低沉、慵懒；面无表情地吐槽 | 心理阻抗、少数人影响、被误会的那个、社会比较、过多选择 |
| 路人 | 米灰，没有记忆点 | —— | —— | 不说话（需要时用旁白） | 同事、同学、路人、托儿 |

旁白：三十岁左右的男性讲述者，中低音、温暖，像深夜电台加悬疑纪录片旁白。

声音的完整设计在 `角色.json` 每个角色的 `seed` 里，样本在 `角色库/<角色>/声音样本.wav`（怎么生成、怎么换见 `声音与张力.md`）。改名字、性格：改 `角色.json`，再同步改这张表和 `chibi.py` 的 `CAST`。

旧版（Vox 拼贴）用的是三只猫的真实照片：`角色库/` 里每只 20–30 张，`角色.json` 的「剧照」字段写着每张适合演什么；只在用户要 Vox 风格时用。

## 世界观：四个舞台

括号里的「照片」只对旧版 Vox 有用；v4 用 `props.py` 的道具搭场景（会议桌、手机、窗、门、地板、汽车、猫砂盆、书桌）；没有的道具在镜头函数里用 `fr.d` 画几个色块（示例 `sc_pain` 里的床）。

| 场景 | 适合的情节 |
|---|---|
| **喵喵公司** | 开会、投票、汇报、团建、绩效、加班、背锅（照片：在键盘上、盯着手机） |
| **喵喵大学** | 考试、小组作业、上台演讲、社团、宿舍（照片：在书旁边） |
| **喵喵小区** | 合租、抢沙发、分零食、业主群、邻里纠纷（照片：守着饭盆、坐在门口、钻纸箱） |
| **喵博** | 热搜、评论区、发动态、带货、围观（照片：盯着手机） |

## 讲故事的规矩

1. **一集一个主角，三只猫轮流来。** 选题时看 `进度.md`，上一集是大比当主角，这一集就换胜利或大宝。配角最多两只（另外两只主角或路人）。
2. **性格不变，处境常变。** 大宝永远嘴硬，但它可以是同事、室友、同学。不要为了剧情让角色突然性格大变。
3. **故事是人的日常，不是宠物日常。** 写「开会时不敢说真话」，不写「主人回家猫不理」。猫只是演员，演的是观众自己。
4. **角色台词要短。** 一句 ≤12 字，口语，带口头禅。在 film.py 的 `LINES` 里单独写一句、标 `who='大比'`，并登记到 `SPEAKS`：用角色的声音念，角色自动张嘴，字幕上方挂一个角色色的名牌。旁白负责交代情节和讲知识。
5. **固定的梗**：胜利每集至少一句「稳赢！」然后翻车；大宝的「我不。」；大比总在看别人脸色。老观众会等这些梗。
6. **结尾互动用角色**：「你是大比，还是大宝？」「你身边有没有一个胜利？」这类问题最好回答。
7. **故事是虚构的，知识是真的。** 正文讲的概念、实验、数字以书为准（`book.py` 查），并且说明是人类研究。发布文案会自动加一句「本系列猫咪均为拟人演绎」。

## 选剧照（旧版 Vox）

- 先按情绪在 `角色.json` 的「剧照」里找：委屈、得意、发呆、震惊、心虚、闭眼（无语）、斜眼（不屑）；全身的走、跳、趴、躲、偷看、背影；双猫的对视、背对背、追逐、互舔；生活场景的键盘、书、手机、饭盆、门口、纸箱。
- **脸部特写当满幅照片用**（scene 卡的 `bg`），表情最清楚；**全身照和抠图贴纸用来同框**（scene 卡的 `cat`）。
- 同一张照片一集里最多用两次，而且不要在相邻两镜。
- 照片不够用（比如需要「生气」「哭」）：先看能不能用相近的表情加漫画符号补（委屈＋汗滴＝尴尬，斜眼＋怒气＝生气）；还不够就请用户补拍，或者用 `fetch_images.py` 找同品种的网图当替身（`--coat ragdoll / bicolor / mainecoon`），替身照片需要署名。

## 抠图贴纸（旧版 Vox）

已经抠好的贴纸在 `角色库/<猫>/*_抠图.png`（全身的走、趴、坐在门口，以及几张脸部特写）。需要别的：

```sh
uv run --with "rembg[cpu]" --with pillow python $S/scripts/cutout.py 角色库/大宝/13_全身_伸懒腰.jpg
```

全身照抠得最干净；脸部特写猫占满画面，抠出来下沿是直边（贴纸要贴着卡片底边放），有的边缘会带半透明的雾，用 Read 看一眼，不好就删掉、改用满幅照片。
