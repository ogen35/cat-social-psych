# 猫咪社会模拟实验室（FORMAT = '实验'，线条画风）

一期讲一个能「跑」起来的社会现象。三只主角猫当研究员，上百只小猫当实验对象。观众亲眼看着结果长出来，结论落在书里的研究上。

**为什么做这个：** 国外的模拟实验频道 Primer 累计约 9600 万播放；B 站上用模拟讲人性、社会现象的原创几乎是空白（见 `/root/mao/素材/爆款对标/赛道分析.md`）。

**样片：** `/root/mao/24_第13章-囚徒困境_模拟实验/`，包括 `film.py` 和 `sim.py`。

## 一期的结构（60–75 秒）

| 段落 | 几句 | 做什么 |
|---|---|---|
| 钩子 | 1 | 一个角色说出一句常见的偏见（「老实猫就是吃亏！」），另一只说「那就让 100 只猫试试」，按下按钮，100 只猫弹出来 |
| 规则 | 2–3 | 一句一条规则，画成一张逐行搭起来的规则卡；数字尽量直接用书里的（例：书页 478 图 13.2） |
| 下注 | 3 | 三只猫各押一种策略，押注要符合性格：胜利押最狠的，大比押最善良的，大宝押最冷静的 |
| 模拟 | 3–4 | 先让观众以为猜对了（坑人猫越来越多），再反转；说台词时切到实验室看大屏幕的反应，台词之间的空档切回整村模拟 |
| 为什么 | 2 | 用两三只猫的特写演出机制（两只坑人猫互抢 0:0；互惠猫先分享、被抢就还手） |
| 点名 | 1–2 | 旁白点出术语，并标页码；一句对比总结（「只看一次……；天天见面……」） |
| 收尾 | 2 + 金句 | 大比提一个朴素的问题，大宝用书里的发现回答；最后两句慢读的金句卡 |

## 规矩

- **模拟要先跑够随机种子再写剧本。** 换 20 组随机种子，结局都一样，才能讲成「结论」；结局会变的，就讲「看运气」。用来演示的那组种子要选三幕最清楚的。
- **说清楚哪些是演示设定。** 模拟规则（每天见几次、淘汰几只）是我们定的，要写进 film.py 开头和 META 的 sources；书里的数字和实验另外标页码。
- **画面（一个连续镜头，不来回切）：**
  - 从上到下：人口曲线（`chart`，y 86–170）→ 20×5 的小猫村（`grid`，y 168–252，小猫身高 9）→ 三只主角并排站在地面线 y=334 上看大屏幕 → 字幕带。
  - 模拟这一段从「每天结算」那句一直到「为什么」之前，都是同一个镜头。谁说话谁放大一点（`grow()`，2.3→2.6，0.22 秒平滑过渡），表情和动作留到下一只开口。第 24 期第一版每句台词切去实验室、空档再切回模拟，最短的镜头只有 0.5 秒，看着很卡。
  - 曲线右边留 58 像素放标签（`第 N 天` 在左上），标签永远在线头右边，三个标签上下错开 12 像素，都夹在框里，不会压线或出框。
  - 每天结算时：最穷的 10 只打叉消失，空位上弹出新猫，日期跳一下，配一声轻响。轻响只在看得到模拟的时候响。
  - 小猫用 `fr.mini(策略名, x, 脚底y, 身高, 表情)` 画，先缓存成小图，100 只不卡。
- **「为什么」的卡片：** 每一行在念到对应的词时出现（`T['why2'].at('被抢')`），不要按固定间隔排；数字落在猫耳朵上方，标签放在左边，字号不小于 56。
- **按钮弹出 100 只猫：** 这句说完才切（`L.end`），这句加 `gap≈1.1`，弹出动画才放得完。第一版是在话说到一半时切的，后面又只留了 0.25 秒，一闪就过去了。
- **实验猫只靠颜色区分：** 好人猫粉色、坑人猫紫灰（默认斜眼）、互惠猫浅蓝（`linecat.CAST`）。新的策略照这个格式加，颜色不要和主角重复。
- **时间轴：** `dayf(t, T)` 用几个关键句的开始时刻对齐「第几天」。反转发生在哪句台词，那一天就要卡在那句台词上。

## 书里适合做成模拟的现象（按章）

| 现象 | 章节 | 怎么跑 |
|---|---|---|
| 囚徒困境、GRIT（已做） | 第13章 书页 477–478、511 | 三种策略分鱼，优胜劣汰 |
| 公地悲剧 | 第13章 书页 478– | 一片公共草地（鱼塘），每只猫决定多拿还是少拿 |
| 从众 | 第6章 | 一只猫抬头看天，看看多少只跟着抬头（街头仰望实验） |
| 旁观者效应 | 第12章 | 围观的猫越多，每只出手帮忙的概率越低 |
| 群体极化 | 第8章 | 观点相近的猫凑在一起讨论，越聊越极端 |
| 自我实现预言 | 第3章 | 被认为「聪明」的猫得到更多机会，最后真的变强 |
