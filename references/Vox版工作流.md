# Vox 版：真实猫照片＋网络实拍素材的拼贴桌面

2026-11-09 用户定下，第 31 期反事实思维被评为「最好的一次」，以后都照这一版做：画面严格按 huashu-art-motion 的 Vox 语法（`references/动画语法/y2_vox.md`、`demos/y2_vox`）；内容框架（问题链、一集一个知识点、四个交付文件、抖音文案）照旧。猫用 `角色库/<猫>/` 的真实照片；举例用网上找的素材，**优先动态视频**。

第 31 期第一版用 y2_vox 参数化片段直接放彩色照片，被用户否了：「画风风格不对，配色不对；红圈重点乱画，没有概念可言；MG 动画要丰富；猫说话时要用拼贴的感觉动起来」。现在的做法是专用语法 `cat_vox`（`assets/示例_v8_第3章反事实思维_Vox/cat_vox.js`），下面的规矩就是那次返工定下的。

## 画面规矩（每一镜都守）

1. **只用 Vox 三色**：桌面旧纸 `#e4ddcf`、近黑 `#171716`、一种红 `#b8433f`；荧光黄 `#dacf08` 只用来划字（文字下面的荧光笔、黑标签里的关键词）。不出现彩色照片、彩色背景、彩色名牌。
2. **照片和视频一律灰度网点冲印件**：白边、旧纸色、两条胶带、轻投影（`photo`，视频也逐帧转网点）。暗的素材加 `bright`。
3. **猫是剪纸贴纸**：真实照片抠图（`scripts/cutout.py`，每只猫单独一个输出目录，不然同名文件会互相覆盖），硬边、纸白描边、灰度网点。**说话时拼贴式张嘴**：下巴那块剪纸 12fps 一张一合往下掉，露出弧形的嘴，头一顿一顿；`talk` 写这只猫说的句子 id，按真实出声区间动。每个抠图要标 `mouth: [鼻下 x, 嘴线 y, 下巴 y]`（占图的比例），出一张张嘴那一拍的静帧裁脸核对。
4. **红圈、荧光笔、划掉、盖章只落在「这一句正在说的那个词」上**：剪报标题里的「铜牌」、索引卡上的「本来可能」、时刻表上的「8:02」、分数「89」、纸条上的「要是」（划掉）。时刻写成 `句id@词`。**不圈猫脸、不圈人脸**。
5. **用桌面上的物把概念摆出来**：剪报（研究结论）、横线索引卡（术语、办法、念头）、红线（谁连到谁：银牌往上连「金牌」、铜牌往下连「没牌」）、印章（「差一点 → 金牌」）、时刻表、成绩卡、黑卡纸上的纸条标题。猫的台词镜头放在黑卡纸上（demo 镜 3 的做法），讲证据的镜头放在桌面上。
6. **字幕、名牌、顶部标题也是 Vox 的**：黑底撕边条＋纸白字（关键词荧光黄字），名牌是红底小标签，由 `cat_vox` 画；film.py 写 `OVERLAY = False`，build_pixel 只出声音、封面、文案和自检。
7. **镜头**：相机 60fps 平滑，桌上的东西 12fps 步进。默认停住；推近、拉远、横移、快推只给揭晓和重音，相邻镜换动作。开场 0.3 秒内要有事件（贴纸滑入、快推）。
8. **封面也用 `cat_vox` 出**：同一套纸条标题、网点照片、印章、贴纸；film.py 的 cover_v / cover_h 只把渲好的 PNG 铺满。

## 分工

| 谁 | 做什么 |
|---|---|
| `<集目录>/代码工程/`（`cp -R huashu-art-motion/scripts/engine`，再把 `cat_vox.js` 放进 `clips/`） | 渲每一镜：桌面、冲印件、剪报、索引卡、纸条、红线、红圈、荧光笔、印章、黑卡纸、猫贴纸张嘴、字幕、名牌、顶部标题 |
| `scripts/vox_shots.py` | 读 `镜头表.json`（`"grammar": "cat_vox"`），把所有 `at` / `t` / `labelAt` 按配音时间轴换成镜内秒，`talk` 换成真实出声区间，生成字幕块，裁视频抽帧，渲片段，帧放进 `build/clips/<镜头>/` |
| `build_pixel.py` | 按 SHOTS 播片段，配音、铺底配乐、音效、响度、封面、抖音文案、节奏自检 |

## film.py 设置

照 `assets/示例_v8_第3章反事实思维_Vox/film.py`：

- `FORMAT='问题链'`、`FLAT=True`、`PACE='fast'`、`VOICE='libtv'`、`VOICE_TEMPO=1.35`、`VOICE_MIN_RATE=4.6`、`VOICE_MAX_GAP=0.4`、`GAP=0.2`、`TAIL=1.8`、`AUTOZOOM=False`。
- `TOPBAR` 写全片的核心问题（cat_vox 画成黑底撕边条，关键词在 镜头表.json 的 `topbar.hi` 里标黄）；`OVERLAY=False`。
- `PRE=0.25`、`SHOTS=[(镜头, 从哪句开始), …]`，`SCENES` 用 `_mk` 从 SHOTS 生成；`ANGLES` 每句写一个镜头动作（`--check` 要至少 6 种）。
- `cover_v` / `cover_h` 只铺 `素材/vox封面_竖.png` / `vox封面_横.png`（`--covers` 渲出来的）。
- 台词全片约 380 字（不含标点）≈ 85–90 秒；`--check` 估时超过 90 秒就先删字再配音。页码只写在 `META['sources']`。

## 步骤

1. 写 film.py。每镜 2.5–8 秒，猫的每句台词都有这只猫的剪纸在说。
2. 找素材进 `素材/网络素材/`，`来源.md` 记文件、内容、网址。从这台服务器能直接下：Mixkit（`https://assets.mixkit.co/videos/<id>/<id>-1080.mp4`，没有就 `-720`）、维基共享资源（API 查 `filetype:video`，下 `transcoded/…480p.vp9.webm`）、archive.org。B 站（HTTP 567）、YouTube（要登录验证）下不动；用脚本调 B 站搜索接口会被权限拦（判为绕反爬），不要绕，换源或请用户自己下好放进来。
3. 抠猫：`uv run --with "rembg[cpu]" --with pillow --with scipy python $S/scripts/cutout.py <照片…> --out 素材/抠图/<猫>`（每只猫一个目录；大宝加 `--alpha 40`）。用 Read 看一眼：要有身子，不能只剩一个头。每张标 `mouth: [鼻下 x, 嘴线 y, 下巴 y]`（占图的比例，先粗估，第 5 步核）。
4. 写 `镜头表.json`：世界坐标＝竖屏 1080×1920 的像素（相机 z=1 时），内容放在 y 330–1340（上面是顶部标题，下面是字幕和名牌），`fy: 820`；`covers` 写竖 1080×1440、横 1440×1080 两张封面。字段见 `scripts/vox_shots.py` 开头和 `cat_vox.js` 开头。
5. 看画面（`V="uv run -q --with numpy --with pillow python $S/scripts/vox_shots.py"`）：
   - `$V <集目录> --est --stills`，拼一张总览，对照上面的「画面规矩」逐条看；
   - `$V <集目录> --jaw`，看 `build/vox/张嘴核对.jpg`：嘴缝要在鼻子下面（裁图是按标的嘴线居中的，贴纸本身缺身子时会看着偏，回第 3 步）；
   - `$V <集目录> --covers`，看 `素材/vox封面_*.png`。
6. 配音：`references/配音_SeedAudio.md`（LibTV Seed Audio 1.0）。
7. `$V <集目录>` 按真实时间轴渲全部镜头（spec、语法文件、用到的图片都没变的镜头会跳过；一帧 0.5–1 秒，全片约 30–40 分钟，后台跑），再 `build_pixel.py film.py` 出片。
8. 审片：节奏自检会把相机推拉、滑动报成「切镜」「一闪而过」，按每镜起点（`--plan` 的时刻）分开，真切镜处没有黄灯就对；`build/qa/抽帧.jpg` 对照「画面规矩」再看一遍。

## 配音

只用 LibTV Seed Audio 1.0，见 `references/配音_SeedAudio.md`。LibTV 连不上就停下来请用户重新授权，不改用别的配音。
