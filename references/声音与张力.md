# 声音与张力：让片子有起伏，不像朗读

> **v4 像素剧场（默认）的配乐规则**：全片只铺**一段浅浅的背景音乐**（`film.py` 里 `BGM = '轻松'` 之类），不按段落切换、不抽空、不停顿；**节奏交给音效**——每个弹出、转折、揭晓、反转都配一个音效（写在 `SFX(T)` 里）。下文第 1、2 节的「按情绪换配乐」「停—悬—砸」只用于旧版 Vox 流程；第 3–6 节（音效、红圈配额、口播写法、配音）两种流程通用。

平淡的片子，问题不在内容，在**没有变化**：同一个语速念到底、同一种画面推近到底、重点全靠红圈。这一页讲三件事：**情绪线**（每镜一个 mood）、**重音**（accent：音效＋白闪＋震屏＋大字）、**少画红圈**。配乐和音效由 `scripts/audio_fx.py` 纯代码合成，都是原创，没有版权问题。

## 1. 情绪线：每镜一个 mood

分镜里每一镜写 `"mood"`，没写就沿用上一镜。一个 mood 同时决定四件事：

| mood | 配乐 | 配音 | 画面 | 用在哪 |
|---|---|---|---|---|
| **悬疑** | 低频长音、钟表滴答、心跳低音、偶尔一声不协和高音 | 慢一点、低一点 | 四角压暗（0.55）＋整镜缓慢推近 5% | 开场钩子、实验开始、「接下来发生的事……」 |
| **紧张** | 八分音符低音推进、十六分滴答、越来越满 | 快一点 | 压暗（0.4）＋推近 7% | 实验过程、倒计时、「你猜」之前 |
| **揭晓** | 沿用紧张，但**重音之前把音乐抽空**、上升音蓄力，再砸 | 慢下来、压低，像在宣布 | 压暗（0.35）；重音时白闪、震屏、大字 | 关键数字、结论 |
| **反转** | 换成轻快拨弦；这一镜开头唱片急停 | 快、高 | 开头故障撕裂 | 「但是——」「结果呢？」、角色翻车 |
| **轻松** | 蹑手蹑脚的拨弦 | 轻快 | 基本不压暗 | 故事、角色日常、吐槽 |
| **平叙** | 慢钢琴琶音 | 正常 | 轻微压暗 | 讲定义、解释原因 |
| **温暖** | 柔和和弦＋钢琴旋律 | 放慢、柔和 | 不压暗 | 结局、金句、互动 |

**一集至少用 4 种情绪，并排成一条有起伏的线。** 常用的线：

```
悬疑（钩子）→ 轻松（故事）→ 平叙（这叫什么）→ 悬疑/紧张（实验）→ 揭晓（数字）
→ 平叙/悬疑（为什么）→ 紧张（条件）→ 揭晓（第二个数字）→ 反转（角色翻车或逆袭）→ 温暖（收尾）
```

相邻两段情绪不要一样；连续三段以上同一种情绪，观众就会走神。配乐按情绪段切换，段与段之间自动交叉淡化。

## 2. 重音：accent

一集只留 **2–4 个**真正的重音：揭晓的数字、反转、最狠的那句话。重音写成一个 cue：

```json
{"kind": "accent", "on": "37%", "slam": "【37%】", "sub": "的回答跟着大家错", "sfx": "hit", "blackout": true}
```

| 字段 | 作用 | 默认 |
|---|---|---|
| `on` / `at` | 口播念到哪个词时砸下去 | — |
| `sfx` | 音效：hit（重击）、boom（低沉轰）、sting（悬疑三连）、ding…… | hit |
| `slam` | 大字砸进画面：黑底撕边条＋白字，【】里是黄色。只放数字或两三个字 | 不砸字 |
| `sub` | 大字下面的一行小字 | — |
| `flash` / `shake` | 白闪、震屏 | 都开 |
| `blackout` | 砸之前 0.35 秒黑一下（「停」） | 关 |
| `pulse` | 四角红色脉冲（危险、警告） | 关 |
| `drop` | 砸之前把配乐抽空、用上升音蓄力（「停—悬—砸」） | 揭晓情绪默认开 |
| `lead` | 抽空的时长（秒） | 0.9 |

大字砸入之后会一直留在画面上，直到这一镜结束，所以有 slam 的这一镜不要再放 highlight。

## 3. 音效：自动的和手动的

**自动加的**（不用写）：

- 第一镜是悬疑或紧张：开头一声低沉的轰（boom）
- 换段落（这一镜写了 `title`）：嗖（whoosh）
- 角色台词镜（写了 `who`，情绪不是悬疑紧张）：啵（pop）
- 进入反转：唱片急停（scratch）＋画面故障
- 每个红圈：很轻的一声叮（ding）
- 重音：见上一节

**手动加的**：在 cues 里写

```json
{"kind": "sfx", "name": "heartbeat", "at": 0.2, "gain": 0.7}
```

可用：whoosh 嗖 · hit 重击 · boom 低沉轰 · riser 上升蓄力（`dur` 控制长度，在 `at`/`on` 那一刻结束）· ding 叮 · pop 啵 · tick 滴答 · heartbeat 心跳 · glitch 故障 · scratch 唱片急停 · sting 悬疑「当—当—当」。

音效是「点」，不是「线」：一镜最多一两个，不要每句话都配。

## 4. 红圈和【】的配额

红圈（highlight）和字幕里的黄字（口播里的【】）都是「看这里」。到处都是就等于没有重点。

- **红圈：每一段只圈一个**——这一段最重要的那个词或数字。一集 3–5 个。相邻两镜不要都画红圈。
- **重点交给声音**：数字揭晓用 accent（音效＋大字），故事里的关键句用角色台词或语气，不用每句都圈。
- **口播的【】**：只给每段的关键词，全片不超过四成的镜头有【】。
- build_episode.py 会检查：红圈太多、相邻两镜都有红圈、【】太多、情绪少于 3 种、没有重音、重音超过 5 个，都会亮黄灯。

## 5. 口播：怎么写才不像朗读

朗读感来自「每句话一样长、一样重、一样快」。按下面写：

- **长短句交替**：一句长的交代，接一句短的砸。「七个人坐一排，前面五个全是托儿。你，坐第六个。」
- **设问和停顿**：「你猜，有多少人跟着错了？」后面给 `pause: 0.6`，让观众真的猜一下。
- **反转词前置**：「但是」「结果呢」「问题来了」单独起一句。
- **说给一个人听**：用「你」，不用「我们」「大家」；像在跟朋友讲八卦。
- **数字慢慢说**：揭晓那一镜情绪写揭晓（配音自动慢下来），数字前面留一个逗号。
- **语气词少量用**：「嗯？」「好家伙」「离谱的是」一集一两次就够，多了油腻。
- **角色台词抢戏**：最有情绪的那句给角色说（`who`），用角色自己的声音；旁白退后一步。

### 配音：豆包音频生成，固定音色＋按情绪念

有豆包语音的 API Key 时，配音用豆包音频生成（seed-audio-1.0）：

- **音色固定**：旁白和三只猫各有一个设计好的声音（`角色.json` 里每个角色的 `seed`：`desc` 声音描述、`style` 说话方式、`sample_text` 样本台词）。`seed_voice.py design` 按描述生成一段 15 秒左右的声音样本，存成 `角色库/<角色>/声音样本.wav`；之后每一句都拿样本当参考音频，所以集集都是同一个声音。
- **情绪跟着 mood 走**：旁白按 mood 的语气念（悬疑＝压低放慢、像讲秘密；揭晓＝停半拍再郑重宣布；轻松＝带笑八卦……）；角色台词＝角色的说话方式＋这一镜的情绪。某一句要特别的语气，在那一镜写 `"tone"`，比如 `"tone": "委屈地小声嘟囔"`。
- **换声音**：改 `角色.json` 的 `seed.desc`，再跑 `seed_voice.py design 角色库/角色.json --who 大比 --force`（旧样本自动备份成 `声音样本.旧.wav`）。也可以直接把 `声音样本.wav` 换成自己录的 10–30 秒干声——只用自己或明确同意的人的声音，不要用明星、动漫角色、其他博主的声音。
- **念错字**：模型偶尔会多念、少念或改字。build 会对照返回的字幕检查，念错先自动重试一次，还错就亮黄灯，告诉你念成了什么。句子中间夹着「」引号时（尤其是问句），模型偶尔会把引号里的词挪到句首念，结尾互动句尽量不用引号。
- **时长**：豆包按情绪念，悬疑段会慢、会停顿（实测平均约 4.5 字/秒，比 edge 慢一点）。句中停顿最长留 0.65 秒；一句还是超过 8 秒，会自动加快语速重配一次，再超才要拆镜。悬疑、揭晓那一镜的口播最好控制在 25 字以内。
- **按真实声音裁剪（2026-11-06，第 24 期返工）**：
  - 豆包返回的逐字时间不可信：整体常常早 0.2–0.5 秒；数字「100」一个词能占 1.7 秒；有的句子开头有 1 秒静音，却标成从 0 秒开始念。
  - 旧版按这些时间裁音频，20 句里剪掉了 9 句的最后一个字，「那就让100只猫试试」还先出了 1.2 秒字幕和张嘴、声音才到。
  - 现在 `seed_voice.fit()` 只看波形：
    - 去掉开头静音，留 50 毫秒；
    - 句尾留 160 毫秒余音，最后 100 毫秒淡出；
    - 句中超过 0.65 秒的停顿剪短；
    - 逐字时间平移、缩放到真实发声区间；时间戳离谱时，按音节平均分配。
  - **模型自己也会截断句尾**：最后一个字还在正常音量上就结束了。build 会检测出来，自动重新生成，重试时在提示词里加一句「最后一个字要完整念完、自然收住，念完以后留一秒安静」。
  - 末尾多出来的爆音、气声（比正文短，前面隔着长静音，逐字时间也显示字早就念完了）会去掉。
  - 原始音频存在 `build/tts/seed_*.raw.mp3`：以后改裁剪规则，直接按原始音频重裁，不用花钱重新生成。旧缓存没有原始音频：声音完整的按现有文件重裁，句尾被剪掉的自动重新生成。
- **嘴跟着真实声音动**：`actor()` 只在这句真实出声的区间里张嘴，句中停顿、句尾余音时闭嘴（`Line.voiced`）。
- **速度**：每句要等接口 30 秒到 1 分钟，3 句同时配（只占网络，不占本机 CPU），一集 20 句左右约 7–10 分钟；配过的句子有缓存。
- **费用**：按生成的音频时长计，约 1 元/分钟，一集一两块钱；同一句话缓存，只改了几镜就只重配那几镜。

没有豆包 Key 时退回 edge-tts（旁白 zh-CN-YunxiNeural 云希）：不能指定情感，只能靠 mood 调语速音高，感情有限。

用了 AI 配音，抖音发布时在「作品声明」里勾选「内容由AI生成」（发布文案里会提醒）。

## 6. 换成自己的配乐和音效

- **一种情绪换一首**：把文件放到 skill 的 `assets/配乐/<情绪>.mp3`（或 .wav），比如 `assets/配乐/悬疑.mp3`，这种情绪的段落就会用它（循环铺满、自动对齐响度）。
- **换某个音效**：放到 `assets/音效/<名字>.wav`，比如 `assets/音效/hit.wav`。
- **整片用一首**：`build_episode.py --bgm 文件.mp3`（情绪段的配乐切换和抽空就不生效了）。
- **用抖音热门音乐**：`--no-bgm` 导出不带配乐的版本，在抖音里选音乐。音效还在。

自己的音乐必须有使用授权（自己做的、买的、明确可商用的免费曲库）。网上随便下载的歌不能用。

配乐在人声下会自动避让（人声一出来就压低），整片响度对齐 -14 LUFS（抖音常用的响度）。
