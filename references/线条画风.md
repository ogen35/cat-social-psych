# 线条画风（STYLE = 'line'）

像素画风的替代方案：线条萌猫加线条道具，背景是纯色底配简笔场景。2026-11-05 对标了 18 条爆款科普动画，没有一条是像素风。像素猫特写时脸只是几块方块，表情撑不住；线条猫放到满屏大特写也清楚。

**状态：** 样片 `/root/mao/23d_第3章-易得性_线条版/` 和 `/root/mao/24_第13章-囚徒困境_模拟实验/` 在等用户确认，确认后改成默认画风。

## 怎么切换

film.py 改三处，其余写法和像素版一样（镜头函数、`actor`、`T['id'].at('词')`、`pop`、`hop`、字幕、封面模板）：

```python
from kit_line import *        # 原来是 from kit import *
STYLE = 'line'
# 不用 fr.d（像素画笔）：自己画东西用 fr.rect / ellipse / circle / poly / lines / draw(fn)
```

出片命令要多加 `--with skia-python`：

```sh
X="uv run --with numpy --with pillow --with scipy --with soundfile --with skia-python python $S/scripts/pixel/build_pixel.py"
```

## 和像素版的区别

| | 像素版 `kit.py` | 线条版 `kit_line.py` |
|---|---|---|
| 猫 | `chibi.py`，24 像素小人 ×s | `linecat.py`：矢量绘制，头身一体，深棕粗描边，线条每 3 帧轻微抖动 |
| 猫的大小 | 高 ≈ 25·s 逻辑像素 | 同一个 s 大小差不多（身高 21·s，加耳朵约 25·s） |
| 道具 | `assets/道具库/`（像素） | `assets/道具库_线条/`（108 件，名字和像素版一一对应），`fr.prop()` 写法相同 |
| 背景 | `fr.photo()` 像素化照片 | `fr.scene('room' / 'road' / 'sky' / 'cabin' / 'street' / 'blank', bg=颜色)`，纯色加同色系简笔线；`fr.photo()` 保留高清，只轻微虚化、提亮 |
| 特效 | 像素多边形 | 同名同参数的线条版：`focus`、`burst`、`bolt`、`gloom`、`soul`（小幽灵）、`sparkles`、`puff`、`spot`、`emote`、`paws`，另加 `fr.shock(x, y, r)`（头顶三道惊吓线） |
| 文字和字幕 | 涂鸦层 | 完全一样 |
| 渲染 | 约 7 帧/秒 | 约 12 帧/秒（23d 36 秒的片 93 秒渲完） |

## 角色

- 姿势（10 个）：`stand`、`cheer`、`jump`、`headhold`、`akimbo`、`point`、`think`（托下巴）、`shrug`（摊手）、`flop`（瘫倒）、`slump`（垂头）。
- 表情（17 个）：`normal`、`happy`、`smug`、`flat`、`shock`、`blank`（白眼大张嘴）、`star`、`love`、`xx`、`dizzy`、`sob`、`cry`、`rage`、`grin`、`gloom`、`sad`、`sideeye`（斜眼）。
- 视角：`front`、`side`（脸转向一侧，`flip=True` 朝左）、`back`（背影，尾巴在前）。
- `fr.cat(..., look=-1…1)` 让脸朝某一侧，`wag=` 控制尾巴摆动，`blush=True` 加腮红。`actor()` 会自动眨眼、呼吸、摇尾巴、说话时张嘴。
- 招牌特征：大比是深色耳尖、八字眉、蓝眼睛；胜利戴王冠、尾巴竖着；大宝耳尖有簇毛、额头三道纹，个子大一号。
- 演技表：`assets/演技表/线条_表情.png`、`线条_姿势.png`。

## 配色和构图

- 一个镜头一种底色，跟着情绪换：
  - 夜里、不安：`(62, 72, 112)`，简笔线用亮一点的 `(96, 108, 156)`；
  - 得意、开心：暖黄 `(253, 226, 128)`；
  - 平静：奶油 `(250, 238, 214)`；
  - 讲数据、扎心：灰蓝 `(210, 218, 228)`；
  - 震惊：粉 `(250, 214, 200)`；
  - 天空、机舱：`(196, 226, 242)`。
- 大特写敢放大：「啊？！」那一镜用 `s=12.5`，猫脸占满屏，加集中线、惊吓线、灵魂出窍。这是线条版相对像素版最大的优势。
- **地面线和字幕带（2026-11-06，第 24 期返工定下的规矩）：**
  - 画面从上到下：标题栏 y≈62 → 内容区 y 86–334 → 地面线 → 字幕带 y≥338（名牌加字幕）。
  - 所有角色的脚踩在 y≤334 的地面上，写 `scene('room', ground=334)`，`actor(fr, 名字, x, 334, s, …)`。猫的身体、名牌、字幕都不叠在一起。
  - 名牌永远在画面正中。猫压在字幕带上时，名牌会贴在中间那只猫肚子上，哪怕说话的是旁边那只。这是第 24 期样片最显眼的错误。
  - 大特写也一样，脚踩地面线，s 最大到 6 左右（头顶约 y 180）。要「整张脸占满屏」的冲击镜头，就去掉这一句的字幕（`cap=False`），把台词做成大字。
  - 出片时自检会逐帧检查：哪句的字幕压在了哪只猫身上，结果写进 `build/qa/节奏.txt`。
- **镜头推近（`fr.zoom`）：** 镜头函数里写的字、贴纸、箭头跟着画面一起推近（标题栏和字幕不动），标签不会再和它标的东西错开。推近会把地面线以下的东西推进字幕带，所以有角色站在地面线上的镜头，不要用自动推镜（【重点词】那句写 `fr.zoom = (1.0, W / 2, 220)` 关掉）。
- **数字：** 涂鸦字体（站酷快乐体）的阿拉伯数字太花，「100」看着像「1口口」，渲染时自动换成得意黑，不用手动写 `kind='smiley'`。
