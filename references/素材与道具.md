# 素材与道具：全部在线上完成

每集的画面由三样东西拼成：**角色剧照**（三只主角的照片，转灰度网点）、**故事道具卡**（聊天记录、会议纪要这类网感纸件，自己生成）、**知识卡**（读书笔记、实验档案）。主角是用户自己的猫；其余素材来自免费可商用的图或自己生成。

## 目录

1. 素材从哪来：能用的与不能用的
2. 找图：fetch_images.py
3. 抠图：cutout.py
4. 卡片总表
5. 角色剧照卡（scene）怎么摆
6. 署名怎么走

---

## 1. 素材从哪来

| 来源 | 用来做什么 | 授权 |
|---|---|---|
| `角色库/` | 三个主角（用户自己的猫：大比、胜利、大宝）的照片、抠图、头像，每集复用 | 用户自己的素材，不用署名 |
| Wikimedia Commons（照片） | 主角的替身（同品种）、配角、场景照片 | CC0／公有领域／CC BY／CC BY-SA |
| Openverse（插画） | 复古插图、剪影、版画，做拼贴背景或配角 | 只取可商用、可修改的 |
| 自己生成的卡片 | 故事道具、知识卡、封面 | 自己做的，没有版权问题 |
| 自己画的 SVG | 漫画符号、贴纸道具（眼镜、领带、工牌…） | 同上 |

**不能用**：Pinterest、小红书、百度图片、表情包网站、别人的视频截图。这些图大多是转存的，版权在原作者手里，平台不授予使用权；这是给客户做的商业内容，被投诉会下架甚至影响账号。它们可以当**灵感**：看到喜欢的网感，照着用上面的来源做出来。

画面里不能出现**可识别的人脸**（手、背影可以），不能有品牌标志（聊天卡、动态卡都是通用界面，不做成某个真实 App 的样子）。

## 2. 找图

```sh
# 主角的替身：自己的照片里没有需要的动作时，按品种找（ragdoll 大比 / bicolor 胜利 / mainecoon 大宝）
uv run --with playwright python $S/scripts/fetch_images.py "sleeping" --coat ragdoll --out <集目录>/素材/图
# 配角、场景照片：不限花色
uv run --with playwright python $S/scripts/fetch_images.py "kitten group" --out <集目录>/素材/图
# 插画、剪影、复古版画（Openverse）
uv run --with playwright python $S/scripts/fetch_images.py "vintage office" --kind illustration --no-cat --out <集目录>/素材/插画
```

- 照片默认走 Commons（按花色筛得准），插画默认走 Openverse（插画多）。
- 关键词用英文，越短越好；动作词搜不到就留空 `""`，从一批里挑。
- 脚本自动跳过标题里有交配、死亡、受伤、捕猎、裸露等词的图，并打印每张的**原标题**——用 Read 看预览时一起看标题，缩略图看不出的问题常写在标题里。
- 挑完把不用的图删掉（连同 `credits.json` 里那一条），素材目录保持干净。

## 3. 抠图

```sh
uv run --with "rembg[cpu]" --with pillow python $S/scripts/cutout.py 角色库/大宝/13_全身_伸懒腰.jpg [更多图…]
```

输出 `<原名>_抠图.png`（透明底，裁到猫的边缘），署名自动跟过去。第一次运行会下载约 176MB 的模型，之后每张几秒。用在 scene 卡里当贴纸：自动加白边、投影、转网点，是 Vox 处理人像的方式（「真人照片剪下来做贴纸」）。

抠完用 Read 看：猫在原图里太小的（脚本会提示）放大会糊；把背景杂物也抠进来的换一张。

## 4. 卡片总表

全部用 `make_card.py` 生成（一个 cards.json 里可以放多张），字段详见脚本开头的说明。文字里用【】标出的词会自动算出坐标，分镜里 highlight 写 `{"mark": 0}` 就能让荧光笔和红圈落在上面。

| 卡型 | 讲故事的哪一步 | 一句话 |
|---|---|---|
| `scene` 角色剧照 | 钩子、情节、反转、结尾 | 网点猫照片或抠图贴纸＋对白气泡＋漫画符号＋贴纸道具＋名牌标签 |
| `chat` 聊天记录 | 情节 | 群聊或私聊截图，角色头像自动从角色库取；支持撤回消息、时间分隔、图片消息 |
| `moments` 动态 | 情节、结尾 | 一条动态＋配图＋点赞＋评论 |
| `memo` 会议纪要／通知 | 情节（职场、小区） | 红色抬头、条目（自动编号；排名这类自己写序号的加 `"numbered": false`）、红色公章（`"stamp": false` 不盖章） |
| `diary` 日记 | 内心戏 | 横线纸、手写体、`~~删掉的字~~` 红色删除线 |
| `hot` 热搜榜 | 钩子、网络事件 | 排名、热度、爆/新/热标签 |
| `book` 读书笔记 | 揭秘 | 概念名＋转述的定义 |
| `study` 实验档案 | 揭秘 | 经典实验：谁、哪年、做了什么、关键数字 |
| `quiz` 先猜一猜 | 揭秘前 | 选择题，答案揭晓时 highlight 对应选项 |
| `vs` 对比 | 照镜子 | 两栏对比（故事里 vs 你身上，或两个角色） |
| `note` 横线索引卡 | 金句收尾 | 手写体一句话 |
| `catlab` 猫咪研究 | 彩蛋（可选） | 真猫研究，见 `猫咪科学资料.md` |
| `cover` 封面 | 封面 | 见 `分镜规范.md` 第 5 节 |

道具卡默认按内容自动定高。卡上的字是给观众**扫一眼**的：聊天记录 3–6 条、纪要 3–4 条、热搜 4–5 条，多了在手机上看不清。

## 5. 角色剧照卡（scene）怎么摆

```json
{"type": "scene", "out": "剧照_大比纠结",
 "bg": "../../../角色库/大比/01_脸部特写_委屈.jpg", "focus": [0.5, 0.4],
 "items": [
   {"bubble": "方案B明明更好……", "x": 0.72, "y": 0.18, "w": 0.44, "to": [0.56, 0.42], "style": "think"},
   {"symbol": "sweat", "x": 0.36, "y": 0.3, "s": 0.08},
   {"tag": "大比 · 喵喵公司", "x": 0.04, "y": 0.84}
 ]}
```

- 两种底：`bg` 一张照片（满幅网点），或者不写 `bg`、用 `cat` 摆几张抠图贴纸（群像、同框、开会）。
- 路径相对 cards.json：卡片放在 `<集目录>/素材/卡片/`，角色库在项目根目录，所以写 `../../../角色库/…`。
- 坐标都是 0..1，相对整张卡（默认 1200×1000）：`x`、`y` 是元素中心（气泡是中心，标签是左上角）。
- `bubble`：`style` 可选 speech（说话）/ think（心里想，尾巴是三个小圆）/ shout（喊，爆炸边）；`to` 指向说话的猫的嘴（或头顶）；`w` 是气泡宽度；气泡里的字 ≤12 个。
- `cat`：抠图贴纸，`h` 是高度占卡片的比例，`flip: true` 左右翻转（让猫面对面）。脚本会提示贴纸是否出界。
- `symbol`：sweat 汗滴、anger 怒气、question 问号、exclaim 感叹号、sparkle 闪光、gloom 黑线、dots 省略号、heart 爱心、shock 冲击线。`s` 是大小（占卡宽）。
- `prop`：glasses 眼镜、shades 像素墨镜、tie 领带、badge 工牌（`text` 写名字）、crown 王冠、gradcap 学士帽、mic 话筒、phone 手机。眼镜放在眼睛上、领带放在下巴下面，`s` 是宽度。
- `tag`：Vox 黑底撕边标签，写角色名和场景（「大比 · 喵喵公司」），每集角色第一次出场时用一次。
- `text`：画面里的红色手写批注。

**摆完一定要用 Read 看一眼**：道具戴歪、气泡尾巴指错猫、气泡挡住猫脸是最常见的问题。一张剧照只放一个主要表情和一两个符号，堆满就不网感了。

## 6. 署名怎么走

`fetch_images.py` 把每张图的作者、授权、来源写进同目录的 `credits.json`；`cutout.py` 抠出来的图会继承原图的署名；`make_card.py` 把卡片里用到的照片（背景、贴纸、头像、配图）记在卡片旁边的 json 里。出片时 `build_episode.py` 顺着这条线把所有需要署名的图（CC BY / BY-SA）列进发布文案，CC0 和公有领域不用列。
