# 费曼脚本：把书里的概念讲给一个完全不懂的朋友听

你是一个擅长把复杂概念讲得通俗易懂的短视频创作者。

## 0. 默认框架（2026-11-07 起）：一个剧情 × 一个知识点 × 问题链

这是用户确认过的写法，平涂版（海螺 H3）每集都按它写。film.py 里写 `FORMAT = '问题链'`。下面第 1–7 节的五段式只在像素版、用户点名要时才用。

**为什么改**：之前的脚本把每个讲解动作（钩子、术语、类比、误解、办法）各写一句就换下一个，观众看到的是一张清单，很碎。对标爆款（大圆镜《第一印象》485 万播放、螃蟹效应、猫的哲学《达克效应》）后，发现它们都是一个核心问题贯穿全片，一层一层往下挖。对标材料和复盘在用户本机的 `/root/mao/素材/爆款对标/复盘_第27期与新框架.md`（不在 skill 里）。

**用户定的硬规矩：**
1. **一条视频只演一个剧情，只讲一个知识点。** 一个主场景、一条故事线，从头演到尾。中途不跳到别的场景，不换例子，不塞第二个知识点。
2. **不用图标、图表来分析知识，全部用情境演绎来表达。** 不用数字卡、柱状图、箭头、贴纸、题卡、金句卡。知识全靠剧情里角色的台词和动作讲清楚，数字只在台词里说。屏幕上的字只有台词字幕；封面标题照旧。
3. **问题链铺开**：每一层结尾，让一只猫说出观众心里冒出来的反驳或追问；下一层专门回答它。
4. 第一句就对观众说话，让观众本人中招，不是角色之间的对白。
5. 书里的事实要准，页码只写在 `META['sources']`。

**结构：**

| part | 回答什么 | 怎么写 |
|---|---|---|
| `开场` | — | 让观众中招（答一道书里的题、做一个选择），同时抛出全片的核心问题。第一句有「你」，≤ 20 字左右 |
| `层1·是什么` | 是什么 | 剧情里的角色当场中招 → 旁白一句带出书里的证据 → 角色点名、翻成大白话 |
| `追问` | ↓ | 角色说出观众心里的反驳（「那是我这题不熟！」） |
| `层2·为什么` | 为什么 | 剧情推进一轮，把机制当场演出来 → 一句解释 → 书里的证据 |
| `追问` | ↓ | 「那我多输几次，总能学乖吧？」 |
| `层3·…` | 更深、更反直觉的一层 | 常常是「为什么改不掉」或「最得意的那个自己也中招」 |
| `追问` | ↓ | 「那怎么办？」 |
| `层4·办法` | 怎么办 | 书里的办法，要正好对准前面的「为什么」。剧情最后一轮，中招的角色用上办法，结局变了 |
| `结尾` | — | 回到观众：一句站在观众这边、能截图的话 |

- **每层 3–5 句**：一个演示、一句解释、一个证据，讲透了才进下一层。
- **层数跟着书走**：3–4 层，约 70–90 秒。
- **层与层之间要有因果**：用「因为、所以、可是」连起来，不是并列罗列。
- **剧情跟着层推进**：每层一轮游戏或一个转折；角色要有弧线，比如中招的赢回来一次，最得意的露馅。
- **观众至少被拉进来两次**：开场答题，中间「你是不是也……」，结尾回到观众。
- **互动问题写进置顶评论**，结尾不念。

**`--check` 会查**：
- 红灯：第一句不是 `开场`、层数少于 3、`追问` 少于 2 句、没有 `办法` 层。
- 黄灯：追问由旁白说、第一句没有「你」、旁白超过 40%、film.py 里还在画图表或贴纸。

**范例**：`assets/示例_v7_第3章过度自信_问题链/`（第 27b 期，客厅里的「九成八把握挑战」，一场戏、四层，89.8 秒）。

以下是旧的五段式（像素版用）。每一集都按下面的顺序写，**一段都不能少，顺序不能乱**。写完先填文末的自检表。

## 完播优先（默认）：30–45 秒

完播率要看到最后一秒才算。实测旧写法（67–103 秒、每秒 3.4 字、第 16 秒才进正文、结尾拖 10–14 秒、7–8 秒才换一个镜头）完播率很差。新集默认按下面写，film.py 里加 `PACE = 'fast'`。

| 段 | 时长 | 写法 |
|---|---|---|
| ① 钩子 | 0–2.5 秒 | ≤ 14 字；第一帧就有动作和大标题，第 0.1 秒开口 |
| ② 痛点 | 2–5 秒 | 一句，最好是角色自己喊出来（「谁？！」） |
| ③ 承诺 | ≤ 2 秒 | ≤ 12 字，同时吊一个悬念：「厨房里到底是谁？最后揭晓」 |
| ④ 正文 | 20–30 秒 | 术语翻译、为什么、类比、误解、办法，各一句，每句 ≤ 25 字 |
| ⑤ 收尾 | ≤ 3 秒 | **故事的答案放在这里**；互动问题只放字幕，下期预告写进置顶评论，都不念 |

- **悬念留到最后**：钩子抛出的问题，答案放在最后 5 秒，看完才知道。
- **1.5–3 秒换一个镜头**：大特写、切角度、分屏、推近；同一句里也要变。
- **不念**「大家好」「今天聊」「关注我」「下期聊」；一集只讲一个概念、一个实验或一个数字。
- `PACE = 'fast'` 会自动：配音每秒 5 个多字、句间停 0.12 秒、片尾 0.8 秒、念到【重点词】镜头推近、字幕大一号；`--check` 会提醒超过 50 秒、钩子太长、收尾太长、镜头太久。
- 示例：`assets/示例_v5_第3章启动效应/film.py`（12 句、约 35 秒、12 个镜头）。
- 长版（60–120 秒）只在用户要「讲透版」时做，下面的五段写法照旧。

## 1. 五段结构

| 段 | 时长 | 要做到什么 |
|---|---|---|
| ① 钩子 | 0–3 秒 | 一句话让人停下来。从四种里挑最合适的一种：**反问 / 反常识 / 数字 / 冲突** |
| ② 痛点共鸣 | 3–10 秒 | 说出观众心里正在想的那句话，让人觉得「说的就是我」 |
| ③ 本期承诺 | 1 句 | 明确告诉观众看完能得到什么：解决什么问题、学会什么、避开什么坑 |
| ④ 正文（费曼讲解） | 主体 | 大白话 + 一个生活类比 + 术语当场翻译 + 纠正一个常见误解 + 一个能用的办法 |
| ⑤ 收尾 | 1–2 句 | 顺着内容自然收：问观众一个具体问题 / 提醒收藏 / 引出下一期。不生硬喊口号 |

总长 60–120 秒：概念简单的 60–80 秒，有实验、有原因的 90–120 秒。**不凑数，也不硬压。**

## 2. 每段怎么写

**① 钩子**：第一句就是钩子，不铺垫、不说「大家好」「今天我们来聊」。
- 反问：「朋友已读不回，你第一反应是什么？」
- 反常识：「人越多，越没人帮你。」
- 数字：「三次回答里，就有一次跟着别人错。」（数字要换成人能感受到的说法）
- 冲突：「明明 B 是对的，你会跟着大家选 A 吗？」
画面上：第一帧就有角色和冲突，标题大字压在上面。

**② 痛点**：用观众自己的生活场景，一两句就够。
- 「开会时，心里觉得不行，嘴上却说：我没意见。」
- 「它是不是生气了？是不是早就嫌我烦？脑补了一整晚。」
可以让角色用自己的声音说一句（`who='大比'`），比旁白念更像真的。

**③ 承诺**：一句话，具体。
- 「一分钟，看懂你为什么总把别人往坏处想，再教你一招：换个镜头看。」
画面上：一张「今天学会」小清单或角色举起道具，讲到哪一条就勾哪一条。

**④ 正文**：按「问题 → 演出来 → 答案」一小段一小段往下走。必须有：
- **术语当场翻译**：术语出现的那一句就翻成大白话。「这叫【基本归因错误】。说白了：把处境的锅，算在人头上。」
- **一个生活类比**：观众天天遇到的事。「就像有人超你的车，你骂他路怒——可他也许是开会快迟到了。」类比要能**演出来**。
- **纠正一个常见误解**：先说出大家以为的，再用书里的证据翻过来。「你以为聪明人不会这样？书里说，聪明、会社交的人反而更容易犯。」
- **一个能用的办法**：兑现第 ③ 段的承诺。「下次先问一句：如果我在它的处境，会不会也这样？」
- 书里有经典实验时，挑**最能演的一个**讲，讲清谁、怎么做、结果；数字换成「三次里有一次」这种说法。不堆实验、不列表格。

**⑤ 收尾**：
- 问一个具体、好回答的问题：「你被谁冤枉过？评论区说说。」
- 自然引出下一期：「下期聊：为什么一旦认定，就很难改。」（按书的顺序选下一个概念）
- 收藏提醒只在内容「以后用得上」时说：「收藏这期，开会前看一眼。」

## 3. 讲法的规矩

- **悬念链**：每一小段的答案放在段尾；下一段第一句是 10 字以内的问句或转折（「为什么？」「可是……」「那怎么办？」）。观众在答案揭晓处最容易走，所以答案后面立刻抛下一个问题。
- **演出来，不念出来**：每一句口播都要对应一个角色动作（转头、举牌、走过去、翻身、刨手机……），写不出动作的句子，多半是在念书，改写或删掉。
- **少用图表**：一集最多一张图表；能用角色演出来的（排队、分组、谁先举手），就不画柱状图。
- **知识以书为准**：定义、例子、数字、原因都来自书（`book.py` 查，带页码）；故事是虚构的，说清研究对象是人。
- **大白话**：一句话只讲一件事；不用「显著」「机制」「认知资源」这类词，非用不可就马上翻译。

## 4. 口播怎么写才不像朗读

- 长短句交替：一句交代，一句短的砸下去。
- 设问后留停顿：问句那一行加 `gap=0.5`，让观众真的想一下。
- 反转词单独起句：「其实，……」「可是……」「问题来了。」
- 说给一个人听：用「你」，不用「大家」「我们」。
- 最有情绪的那句给角色说（`who`），用角色自己的声音。
- 一句 ≤ 34 字；超过就拆成两句（豆包按情绪念会更慢）。
- 句中别夹「」引号的问句（豆包偶尔会把引号里的词挪到句首）。
- 不用绝对化说法：一定、所有人、100%、科学证明、永远。

## 5. 平台差异

| | 抖音 | 视频号 | 小红书 |
|---|---|---|---|
| 画幅 | 9:16（电脑端上传要竖封面 3:4 ＋ 横封面 4:3） | 9:16 | 9:16（封面用 3:4） |
| 节奏 | 最快，钩子要最狠 | 稳一点，少用网络梗 | 干货感：「学会了什么」要清楚 |
| 标题 | ≤ 30 字，放钩子 | 稳重、带出处，适合转发 | ≤ 20 字，带一个表情 |
| 正文 | 爆款简介五行：钩子 → 干货 → 问题 → 收藏/下期 → 出处，3–5 个话题（见 `抖音发布.md`） | 说清出处和结论 | 分点写干货（💡📖✅），结尾带话题 |
| 结尾互动 | 评论区抛问题 | 引导转发给某个人 | 引导收藏 |

在 film.py 的 `META['platforms']` 里写各平台自己的标题和正文。成片三个平台通用；出完抖音版后，用 `--publish-only --platform 小红书`（或 `视频号`）几秒钟出那个平台的 `发布文案_<平台>.md` 和封面，不用重渲。

## 6. 写进 film.py

每句口播写一个 `part`：`钩子`、`痛点`、`承诺`、`正文·术语翻译`、`正文·生活类比`、`正文·纠正误解`、`正文·办法`、`正文·实验`、`正文·为什么`、`正文·真相`、`收尾`（「正文·」后面可以自己起名，但「术语翻译」「生活类比」「纠正误解」三种必须有）。`build_pixel.py --check` 会检查：五段都在、顺序对、正文里有「术语翻译」「生活类比」「纠正误解」，钩子不超过 20 字，没有绝对化用词，一句不超过 34 字。
