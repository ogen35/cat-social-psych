# 像素剧场：角色、镜头角度、动作、构图、文字、声音

v4 的画面 = **像素层**（角色、场景、道具，270×480 逻辑像素 ×4）+ **涂鸦层**（所有文字和标注，1080×1920 高清）。
工具：`scripts/pixel/kit.py`（画面）、`chibi.py`（角色）、`props.py`（道具）、`doodle.py`（涂鸦）、`build_pixel.py`（出片）。
示例：`assets/示例_v4_第3章基本归因错误/film.py`（10 个镜头、9 种角度）。
另有线条画风（`STYLE='line'`，`kit_line.py`），接口相同，区别见 `references/线条画风.md`。

## 1. 角色

| 角色 | 样子（单色 + 一个记忆点） | 性格 | 招牌 |
|---|---|---|---|
| 大比 | 奶白 · 深色耳尖和尾巴 · 蓝眼睛 · 八字眉 | 乖巧、怂、在乎别人怎么看，总想太多 | 冒汗、脑补 |
| 胜利 | 金黄 · 小王冠 · 竖起的大尾巴 · 眯眼得意 | 自信过头、爱吹牛，常翻车 | 「稳赢！」 |
| 大宝 | 灰蓝 · 耳尖簇毛 · 额头三道纹 · 死鱼眼，个子大一号 | 冷静、话少、嘴硬、爱唱反调 | 「我不。」 |
| 路人 | 米灰，没有记忆点 | 同事、同学、路人 | 衬托主角 |

- 一集一个主角，三只猫轮流当；另外两只当配角。故事是人的日常（开会、考试、聊天、排队、通勤），猫只是演员。
- 性格不变，处境常变：大宝永远嘴硬，但可以是同事、室友、陌生人。
- `fr.cat(名字, x, 脚底y, s=倍数, view=角度, expr=表情, talk=张嘴, flip=朝左, rot=旋转90°的次数)`
  - `view`：`front` 正面、`back` 背面、`side` 侧面（默认朝右，`flip=True` 朝左）、`top` 俯视
  - `expr`：`normal happy sad shock smug flat angry cry`；不写就用招牌表情（大比 normal、胜利 smug、大宝 flat）
  - `s`：远景 2–3，中景 4，近景 5–6，大特写 8
- 头顶符号 `fr.emote('sweat' | '!' | '?' | 'anger' | 'heart' | 'spark' | '...', x, y, s=3)`。
- 第一人称看到的爪子：`fr.paws('大宝', y)`。

## 2. 镜头角度（每集至少 4 种，在 film.py 的 `ANGLES` 里登记）

| 角度 | 什么时候用 | 怎么拍 |
|---|---|---|
| 远景 | 交代场景、多人关系 | 角色 s=2–3，地板 + 一两件道具 |
| 正面中景 | 角色表态、吹牛 | s=4–5，正面 |
| 特写 | 情绪爆点、内心戏 | s=6–8，背景压暗或打点模糊 |
| 过肩 | 看手机、看屏幕、看别人 | 前景是角色的背影（`view='back'`，s=6，压在画面一角），后景是它在看的东西 |
| 俯视 | 床上翻来覆去、猫砂盆、桌面、排座位 | `view='top'`，地板用方砖（`props.floor(top=True)`） |
| 侧面 | 走路、开车、追赶、对峙 | `view='side'`，两只猫面对面用 `flip` |
| 主观 | 「我」看到的：手机、手里的东西 | 画面下方两只爪子（`fr.paws`），东西正对镜头 |
| 背面 | 离开、孤独、面对一群人 | `view='back'` |
| 分屏 | 对比两种视角 / 两种结果 | 上下两格（竖屏用上下，不用左右） |
| 取景器 | 「换个镜头看」「别人眼里的你」 | `fr.viewfinder(...)` 框住一部分画面 |
| 特写→拉远 | 揭晓「原来还有这些」 | 先 s=8 只看脸，下一刻切 s=3 的全景，再弹出贴纸标注处境 |

**同一个镜头里也要动**：讲解时不要一张图停 5 秒；用切角度、推拉（换 s）、角色走位让画面一直在变。

## 3. 动作库：让每一句都有动作

时间都用配音时间轴：`T['句子id'].start / .end / .at('词')`。

| 动作 | 写法 |
|---|---|
| 弹入（气泡、贴纸、牌子） | `v, dy = pop(t, T['x'].at('词'))`，显示时 y 加 dy |
| 说话张嘴 | 在 `SPEAKS` 里登记角色的台词 id，`actor()` 自动张嘴 |
| 眨眼、呼吸 | `actor()` 自动 |
| 走路 | `x = walk_x(t, t0, t1, x0, x1)`，`walk=(t0, t1)` 换脚 |
| 翻身、来回 | 每 0.45 秒换一次 `flip` 或 `rot` |
| 震一下 | `x + shake(t, t0)` |
| 速度线 | `fr.motion(x, y, 3, 14)` |
| 聚光灯 | `fr.spot(cx, cy, r, a)` |
| 转场 | 在 `WIPES` 登记，一集 2–3 次就够，不要每段都扫 |

一句口播至少一个动作；关键词上要有「事件」（弹出、翻牌、切镜头、音效）。

### 夸张演技（猫 meme 爆款靠的就是这个）

站着不动、只换眼睛是不够的。情绪点上要用**姿势 + 表情 + 特效**三件套，演技表见 `assets/演技表/`。

| 情绪 | 姿势 `pose=` | 表情 `expr=` | 特效 |
|---|---|---|---|
| 吓傻、崩溃 | `headhold` 抱头 | `blank` 白眼 | `fr.focus()` 集中线、`fr.bolt()` 闪电、`fr.soul()` 灵魂出窍 |
| 得意、赢了 | `jump` 跳起（`lift=hop(t, t0)`）或 `cheer` 举手 | `star` 星星眼、`grin` 咧嘴 | `fr.burst()` 身后爆炸星、`fr.sparkles()` 闪光 |
| 下决心、发火 | `point` 伸手指（flip 朝左） | `rage` 咬牙红脸 | `fr.burst()`、`shake()`、`fr.motion()` |
| 怀疑、看不起 | `akimbo` 叉腰 | `flat`、`smug` | 头顶白色大问号 `fr.text('?')` |
| 沮丧、绝望 | `slump` 垂头耷耳 | `gloom` 脸发黑、`sob` 嚎哭 | `fr.gloom()` 头顶乌云 |
| 累瘫、摆烂 | `flop` 瘫成一摊 | `xx` 眯成 >< | `fr.puff()` 落地烟 |
| 心动、上头 | `cheer` | `love` 爱心眼 | `fr.sparkles(col=TOMATO)` |
| 被绕晕 | 任意 | `dizzy` 转圈眼 | `shake()` |

- 写法：`actor(fr, '大比', x, by, s, t, T, expr='blank', pose='headhold')`；跳起来：`lift=hop(t, T['x'].start, 20)`，影子留在地上。
- 一集至少 4 个情绪点用三件套：钩子第一帧、转折、震惊反应、结尾包袱。
- 深色背景上集中线用浅色：`fr.focus(cx, cy, r, t, col=(226, 226, 236))`。
- 底部字幕已经有的话，不要再做成贴纸重复一遍；贴纸和大字只放字幕里没有的信息（数字、对比、出处）。

### 道具库：一句话配一个道具

爆款科普几乎每句话都配一个道具。先查道具库，没有的再用代码画。

- 总览：`assets/道具库_总览.png`（108 件：交通、医疗、钱、学校、办公、家居、吃的、猫咪用品、比赛、心理学道具、天气）。
- 写法：`fr.prop('墓碑', x, 底边y, s=2)` 整数放大；`h=26` 按高度缩小；`dark=0.8` 放在夜景里压暗；`flip=True` 左右翻。
- 用法举例：数字往上跳时一排排冒出小墓碑；说出术语时角色旁边亮起 `灯泡`；喊「开车！」时手指的方向弹出 `汽车`；路边 `小树`、`路牌` 往后掠，表示在开车。
- 缺道具时用 LibTV 补：提示词模板和导入命令见 `scripts/props_import/提示词模板.md`，一张图出 9 件。

## 4. 构图与安全区（逻辑像素）

- y 30–100：钩子大标题、术语标题（`fr.title`）
- y 100–340：角色和情境；主角放在三分线上，别和字幕抢
- y 355：字幕（自动）；y 380 以下是平台的按钮和简介区，不放重要东西
- 右侧 x > 230、y 225–400 是点赞评论按钮区，主角的脸不要放进去
- 背景要么是纸色，要么是情境色（夜里用深蓝 `NIGHT`），不要花纹满屏
- **真实照片背景（推荐）**：`fr.photo(路径, fx=, fy=, zoom=, dark=, tint=, blur=)` 把照片裁成画幅、缩到同一个像素网格、减到 32 色，颗粒和猫一致。夜景 `dark=0.5–0.85` 加 `tint=(36, 46, 96)`；大特写背景加 `blur=2`；分屏给 `x, y, size`。照片放在集目录 `素材/图/`，用 `scripts/fetch_images.py "关键词" --no-cat --kind photo --no-sa --out <集目录>/素材/图` 找（只下可商用授权，署名写进 credits.json）。优先 CC0；CC BY 要把作者、授权写进 `META['sources']` 和抖音简介的 `source`；**不用 CC BY-SA**；画面里不能有认得出的人脸、品牌和店名。猫要碰的东西（手机、食物、开关）仍然画像素。示例：`assets/示例_v5_第3章启动效应/film.py`
- 颜色固定含义：黄 = 主角 / 重点，番茄红 = 坏消息、误会，青绿 = 真相、对的做法
- 封面用爆款模板 `META['cover'] = dict(line1=, line2=, hi=, who=, expr=, emote=, bg=, tag=)`，竖 9:16、竖 3:4、横 4:3 自动各排一版，不截静帧；写法见 `抖音发布.md` 第 1 节。出片后三张封面都用 Read 看一眼

## 5. 文字：涂鸦层（`doodle.py`）

- 字体：站酷快乐体（手写粗体，OFL），数字和时间用得意黑（OFL）。**不用像素字体写字**（手机上看不清）。站酷快乐体缺的符号（≠ → ★ ① ② 等）会自动换成得意黑；两个字体都没有的（✓ ✗）别写进字里，勾和叉用 `fr.wiggle` 手画。
- 所有字都有白描边：`fr.text(...)`、`fr.title(...)`；关键词标红 `hi='词'`，马克笔底 `mark='词'`。
- 贴纸 `fr.sticker('真相', x, y, 56, 底色, 字色, 角度)`；气泡 `fr.bubble('……', x, y, 52, think=True, tail=(x, y))`；手画箭头 `fr.arrow(...)`；手抖的线 `fr.wiggle(...)`。
- 上屏的字少：气泡 ≤ 8 个字，贴纸 ≤ 6 个字，标题 ≤ 10 个字；口播交给字幕。

## 6. 声音：一段铺底 + 音效带节奏

- 配乐：**全片一段浅浅的铺底**（`BGM = '轻松'` 等），不按段落切换、不抽空、不停顿，在人声下自动压低。
- 节奏交给音效：每个弹出 `pop`、每次转折 `whoosh`、真相或答案 `ding`、反转 `scratch`、重点 `hit`、心事 `tick`、紧张 `heartbeat`。写在 `SFX(T)` 里，时间就是画面事件的时间。
- 一秒内别叠三个以上音效；`hit` 一集 2–3 个。
- 配音：豆包固定音色，旁白按每句的 `mood` 换语气，角色台词用角色自己的声音（`who`），单句语气写 `tone`。

## 7. film.py 模板

```python
from pathlib import Path
from kit import *          # build_pixel.py 会把 scripts/pixel 加进路径
import props as P

PACE = 'fast'               # 完播优先：30–45 秒（见 费曼脚本.md 开头）
IMG = Path(__file__).parent / '素材' / '图'   # 背景照片

LINES = [dict(id='hook', say='……？', mood='悬疑', part='钩子'),
         dict(id='pain', say='……', mood='紧张', part='痛点'),
         dict(id='promise', say='……', mood='平叙', part='承诺'),
         dict(id='term', say='这叫【……】。说白了：……', mood='平叙', part='正文·术语翻译'),
         dict(id='ana', say='就像……', mood='轻松', part='正文·生活类比'),
         dict(id='myth', say='你以为……？其实……', mood='揭晓', part='正文·纠正误解'),
         dict(id='fix', say='下次……', mood='温暖', part='正文·办法'),
         dict(id='end', who='大宝', say='（故事的答案或一句吐槽）', mood='平叙', part='收尾')]   # 互动问题放字幕和置顶评论，不念
BGM = '轻松'
WIPES = [('term', '这叫什么')]
SPEAKS = {'大比': []}                 # 角色台词的 id（自动张嘴）
def sc_hook(fr, t, T):                # 每个镜头一个函数：fr 是这一帧，t 是整片时间
    fr.photo(IMG / 'xxx.jpg', dark=0.6, tint=(36, 46, 96)); ...   # 先铺像素化照片背景，再画猫和道具
SCENES = [('hook', sc_hook), …]       # 从哪一句开始用哪个镜头
ANGLES = {'hook': '过肩', …}          # 至少 4 种
def SFX(T): return [(T['hook'].start, 'pop', 0.6), …]
COVER = dict(line1='≤8字', line2='≤7字大字', hi='标黄的词', who='大宝', expr='shock', emote='!', bg='素材/图/xxx.jpg', tag='概念名')
META = dict(title=…, cover=COVER, sources=[…],          # 爆款封面模板，见 抖音发布.md 第 1 节
            douyin=dict(keyword=…, titles=[3 个], hook=…, points=[…], ask=…, next=…, source=…, tags=[3–5 个], pinned=…),   # 见 抖音发布.md
            publish=dict(titles=[…], desc=…, tags=[…], pinned=…), platforms={'小红书': dict(titles=[…], desc=…)})
```

镜头函数里常用的骨架（每个角色交给 `actor()`，它负责眨眼、呼吸、说话张嘴，见示例 film.py）：

```python
def sc_truth(fr, t, T):
    L = T['truth']
    P.floor(fr, 0, top=True); P.litter_top(fr, 34, 118, 236, 262)
    actor(fr, '大宝', 140, 240, 4, t, T, view='top')
    v, dy = pop(t, L.at('猫砂盆'))
    if v: fr.sticker('这才是原因', 75, 308 + dy, 56, TEAL, (255, 255, 255), 4)
```
