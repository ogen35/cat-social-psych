# 平涂版（H3 情境剧场）的场景和镜头步骤

2026-11-08 以前的默认画面；2026-11-09 起默认改为 Vox 版（`references/Vox版工作流.md`）。用户点名要平涂、H3 时，用这两步替换 SKILL.md 的第 4、5 步，并守下面的规矩：

- **前爪着地**：猫的表演用头、耳朵、眼睛、尾巴和整个身体；道具自己立着。唯一的例外是后腿站立、两只前爪一起举高欢呼。每只猫始终是四条腿、一条尾巴。
- **画风**：按 `references/画风模板.md`。直接出图用 Style Image V8.2（`mj-v8.2`），改图用 AutoPic（`lib-prism`）。LibTV 出图都写明 `count`。风格提示词只写画面特征，不点名艺术家、IP 或品牌。用户给的参考图只用文字描述，不上传。
- 镜头用海螺 H3 多参，一个一个排队提交。

## 4. 场景和道具

**场景为内容服务**（用户 2026-11-08 定）：每一集按剧情选最能把这个知识点演出来的地方，比如猜规律用答题舞台、猜新邻居用楼道、怕坐飞机用候机厅。剧情要用到的线索和道具直接画进场景图，比如邻居门口的搬家纸箱、挂着的外卖头盔。

1. 先查 `assets/平涂/场景库.json`：库里正好有合适的就用。
2. 没有就按 `references/平涂画风.md` 第 2 节出一张新场景图，有需要再出道具图。
3. 出完下载到 `assets/平涂/场景/`，登记进库。

**做完的标准**：场景图里有剧情每一层要用的东西，地板在下四分之一，画面里没有字。

## 5. 镜头单 → 海螺 H3

按 `references/平涂画风.md` 第 4 节写 `镜头单.json`：

- 每个镜头写 `scene`、`cast`、`camera`、`blocking`、`lines`；
- `blocking` 只写头、耳朵、尾巴和身体的动作；
- 每集 15–18 个镜头，每个 5–8 秒，角度至少 6 种。

然后：

```sh
python3 $S/scripts/flat_clips.py prompts <集目录>    # 拼成 H3 官方格式，写回 镜头单.json，检查 2000 字上限
```

1. 一个一个提交 `generate_video(model='MiniMax-Hailuo-H3', referenceImageNodes=refs, params={ratio:'9:16', resolution:'768P', duration:…, count:1})`。
2. 生成完，用 `inspect_media` 拿视频地址。
3. 每个镜头跑：
   ```sh
   python3 $S/scripts/flat_clips.py fetch <集目录> <镜头> <url>   # 下载，量出片段里每段说话的起止
   python3 $S/scripts/flat_clips.py sheet <集目录> <镜头>         # 联系表：动作和构图
   python3 $S/scripts/flat_clips.py limbs <集目录> <镜头>         # 放大看爪子
   ```

**做完的标准**：每个镜头都用 Read 看过 `limbs` 大图，并且都满足：
- 每只猫的前爪都数过，是两只；
- 没有人手，没有手指；
- 猫像设定图；
- 猫够大，在画面上四分之三里。

不合格的只改这一个镜头的 `camera` 或 `blocking`，单独重新生成。
