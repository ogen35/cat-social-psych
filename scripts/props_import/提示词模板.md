# 道具库出图：LibTV 提示词模板

- 模型：**Lib Image 2.5 Pro**（`lib-image-2.5-s`）。参数 `ratio=1:1`、`resolution=1K`、`background=transparent`、`count=1`。
- 一张图 = 3×3 = 9 件道具。物件按「从左到右、从上到下」写，导入时名字也按这个顺序。
- 2026-11-05 对比测试：General image Pro 的线条偏细、书和手机画坏了；Lib Image 2.5 Pro 透明底、粗描边、配色贴近调色板，选它。
- 不要让模型画猫：三只主角猫只用 `chibi.py` 画，保证长相统一。

## 固定的风格前缀（原样复制，只换 Objects 那一段）

```
A sprite sheet of 9 separate game props arranged in a strict 3x3 grid, each object centered in its own cell with wide empty space between cells. Style: chunky retro pixel art, 16-bit, big visible square pixels, flat colors only, no gradients, no anti-aliasing, no shading noise, every object has a clean 1-pixel dark outline (#24202C). Limited warm palette: cream #F5EFE4, warm yellow #F5C247, tomato red #E5533C, teal #2C9684, sky blue #96C8E6, grey #CCC4B4. Cute, simple, readable at tiny size, like icons in a cozy cat game. Objects (left to right, top to bottom): 1 …, 2 …, … 9 …. No text, no letters, no numbers, no grid lines, no frames, no shadows on the ground, transparent background.
```

- 物件里要出现的数字、字，全都不要让模型画，后期用涂鸦字加。
- 有脸的东西（太阳、月亮）写 `no faces`；画到猫相关物件时写 `no cats`。

## 导入

```bash
uv run --with numpy --with pillow --with scipy python -I scripts/props_import/import_sheet.py 图.png 名1,名2,…,名9 --source "LibTV Lib Image 2.5 Pro · 日期 · 批次"
```

- 输出到 `assets/道具库/名字.png`，最长边 56 逻辑像素，≤16 色，外圈补深色描边；`index.json` 记来源。
- 同目录生成 `图_检查.png`，人工看一眼再用；某格没切出来会报「第 N 格没找到物件」。

## 线条画风的道具（`STYLE='line'` 用，2026-11-05，共 108 件，名字和上面的批次一一对应）

参数同上，但 `resolution` 不写（用默认 2K）。固定前缀：

```
A sticker sheet of 9 separate props arranged in a strict 3x3 grid, each object centered in its own cell with wide empty space between cells. Style: cute minimal line-art doodle illustration: thick hand-drawn dark brown outline (#3A261C) of even weight around every object and its inner details, flat solid fill colors, no gradients, no shading, no texture, simple rounded chunky shapes, slightly wobbly hand-drawn lines. Soft warm palette: cream #FCF6EA, warm yellow #F8C04C, tomato red #E5533C, teal #2C9684, sky blue #96C8E6, light grey #D6D0C4, pink #FF9696. Objects (left to right, top to bottom): 1 …, 2 …, … 9 …. No text, no letters, no numbers, no grid lines, no frames, no ground shadows, no cats, no faces, transparent background.
```

- 提示词里不要写具体作品或品牌的名字来指代画风，只描述画风本身。
- 导入：`uv run --with numpy --with pillow --with scipy python -I scripts/props_import/import_sheet.py 图.png 名1,…,名9 --style line --source "…"`。不像素化，保留高清抠图，最长边 360 像素，存到 `assets/道具库_线条/`。
- 原图在 `/root/mao/素材/libtv原图/线条/`，总览在 `assets/道具库_线条_总览.png`。
