# 第3章 · 基本归因错误（脚本要点 · 费曼版）

主角：大比（想太多）· 配角：大宝（已读不回的那个）、胜利（用来演「换位」）

| 结构 | 口播 | 情境演出（镜头角度） |
|---|---|---|
| 1 钩子（反问） | 朋友已读不回，你第一反应是什么？ | **过肩视角**：从大比背后看它手机上的聊天框「已读」，大比头顶冒出「它讨厌我？」——静帧 1 |
| 2 痛点 | 「它是不是生我气了？」「它一直就这么冷淡。」脑补了一整晚。 | 大比在被窝里翻来覆去（俯视），对话框一条条往上冒 |
| 3 承诺 | 一分钟，看懂你为什么总把别人往坏处想，再给你一个「换个镜头」的办法。 | 胜利举起一个像素取景器 |
| 4 正文 · 真相 | 其实，大宝的手机掉进了猫砂盆。 | **俯视**：大宝在猫砂盆里刨手机，砂子乱飞——静帧 2 |
| · 术语翻译 | 这叫「基本归因错误」。说白了：把处境的锅，算在人头上。 | **两种镜头对比**：上半屏取景器里只有大宝冷脸；下半屏是大宝眼里的世界：猫砂、手机、深夜——静帧 3 |
| · 为什么 | 看别人时，人站在画面中间，背景是虚的；轮到自己，你看到的全是处境。（书页 106） | 镜头从大宝的脸拉远，露出整个猫砂盆 |
| · 生活类比 | 就像路上有人超你的车，你骂他路怒——可他也许是开会快迟到了。（书页 104） | 胜利开小车被超，气得冒烟；镜头切到超车的路人猫，手表显示 8:59 |
| · 纠正误解 | 你以为聪明人不会这样？书里说，聪明、会社交的人反而更容易犯。（书页 105） | 戴学士帽的胜利一脸得意，被盖章「也会犯」 |
| · 办法 | 下次先问一句：如果是我在它的处境，会不会也这样？ | 大比把取景器转过来，对准大宝身后的猫砂盆 |
| 5 收尾 | 你被谁「冤枉」过？评论区说说。关注我，下期聊：为什么我们总记得坏事。 | 大宝举着湿漉漉的手机回消息：「刚捞出来。」大比破涕为笑 |

出处：迈尔斯《社会心理学》第11版第3章「基本归因错误」——定义与例子（书页 104）、模拟测验游戏与聪明人更容易犯（书页 105）、视角与情境意识（书页 106）。
